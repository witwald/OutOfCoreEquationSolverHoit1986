# Test_Hoit

This repository represents an implementation of the Hoit (1986) method for an out-of-core blocked skyline equation solver. It applies an optimised method of memory usage for maximum size blocks to support total in-core equation solution by reducing input/output to a minimum. The source code published by Hoit (1986) forms the basis for the code that resides here.

# Reference

Hoit, M. (1986). An Updated Out-of-Core Equation Solver. Computer-Aided Civil and Infrastructure Engineering, Volume 1, Issue 3, Pages 247-254.
https://doi.org/10.1111/j.1467-8667.1986.tb00132.x
